### about

<b>WARFARE</b> is a fast-paced British FiveM deathmatch server built around a heavily modified version of the <b>vRP framework</b>.

while vRP provides part of the original foundation, a large amount of the framework and surrounding systems have been replaced, rewritten or customised specifically for WARFARE.

the server is designed to keep everything simple and responsive, focusing heavily on <b>PvP, optimisation and getting players into fights quickly</b> without unnecessary systems getting in the way.

WARFARE takes inspiration from the style of gameplay found within <b>CMG</b>, giving players from that community somewhere to practice.

WARFARE is an independent project and is not affiliated with CMG.

### development

WARFARE started from a vRP base but has progressively moved away from standard framework behaviour as development has continued.
the aim is to keep the server's codebase focused around exactly what a deathmatch server needs rather than carrying large amounts of unused framework functionality.

### philosophy

WARFARE isn't intended to be a full economy or serious roleplay server.

the idea is intentionally simple — join the server, get equipped and start fighting.

systems are designed around reducing downtime between fights while still keeping enough progression, statistics and server features to make playing feel rewarding.
